このTodoアプリに、次の3つの機能を追加してください。
Apps Script（API）やスプレッドシートの仕組み、src/api.ts と src/config.ts は変更しないでください。今ある機能（登録・編集・削除・完了チェック・検索・並び替え・絞り込みタブ・重要度・期日バッジ・集計カード）はそのまま残してください。新しいライブラリは追加せず、React と Tailwind と lucide-react だけで作ってください。

## 1. 進み具合のバー
- 集計カード（未完了・今日まで・期限切れ）のすぐ下に、横長のバーを表示する
- 「完了 6 / 10件（60%）」のように、完了数・全体数・割合を文字でも表示する
- 割合は全Todoをもとに計算する（検索や絞り込みの影響は受けない）
- 完了にする・戻すと、すぐにバーが動く（なめらかに伸び縮みするアニメーション付き）
- 100%になったら色を緑にして「すべて完了！」と表示する
- Todoが0件のときは「Todoを追加すると進み具合が表示されます」と表示する

## 2. ダークモード切り替え
- ヘッダーの「新規追加」ボタンの左に、月と太陽のアイコンで切り替えるボタンを置く
- tailwind.config.js に darkMode: 'class' を設定し、html 要素に dark クラスを付け外しする方式にする
- 選んだモードは localStorage に保存し、次に開いたときも同じモードにする（初回はパソコンやスマホの設定に合わせる）
- 背景・カード・文字・入力欄・セレクトボックス・タブ・モーダル・トースト通知・スケルトン・バッジ・進み具合のバー・カレンダーなど、すべての部品を暗い色でも読みやすくする

## 3. カレンダー表示
- 絞り込みタブの右側に「リスト／カレンダー」の切り替えボタンを置く（選んだ表示は localStorage に保存）
- カレンダーは月ごとに表示し、「＜」「＞」で前の月・次の月へ、「今月」ボタンで今月に戻れるようにする
- 曜日は日曜はじまり。日曜は赤、土曜は青の文字にし、今日の日付は丸で囲んで目立たせる
- 期日がある日のマスに、その日のTodoのタイトルを小さく表示する（3件を超えたら「他◯件」）
  - 重要度の色の点を付け、完了したTodoは取り消し線＋薄い色にする
  - スマホの幅では、タイトルの代わりに件数の点だけを表示する
- 日付をタップすると、カレンダーの下にその日のTodoの一覧（今のリストと同じカードで、完了チェック・編集・削除ができる）を表示する
- 日付を選んだ状態で「この日に追加」ボタンを押すと、期日がその日に入った状態で新規登録画面が開く
- 検索キーワードと絞り込みタブ（すべて／未完了／完了）はカレンダー表示にも反映する
- 期日がないTodoは、カレンダーの下に「期日なし（◯件）」として折りたたみで表示する

## 共通
- スマホ（幅375px）でも横にはみ出さず、ボタンが押しやすい大きさにする
- 表示の文字はすべて日本語にする
- 完成したら、型チェックとビルドが通ることを確認してください
